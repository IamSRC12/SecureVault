# SecureVault (KeyVault)

A high-security password and API key manager desktop application built with Electron, React, TypeScript, Tailwind CSS, and SQLite.

## Features
- **Master Password Encryption**: PBKDF2/Argon2 password hashing and AES-256-GCM vault encryption.
- **Credential Storage**: Passwords, usernames, domains, notes, and strength evaluation.
- **API Key Storage**: Secret key encryption, service endpoint management, and tracking.
- **Chrome Extension Support**: Auto-fill and auto-save credentials directly from Chrome.
- **Audit Logging**: Local activity auditing and automatic security lock timers.
- **Executables**: Available as both installer setup and standalone portable `.exe` binaries.
- **Real-Time Auto-Sync**: Automatically synchronized with GitHub on file changes.
